# Assets

Папка для изображений, видео и других медиафайлов, используемых в Mini App.

- `images/` — изображения и обложки (PNG, WebP, JPG; для прозрачности — PNG или WebP).
- `videos/` — видеофайлы (предпочтительно MP4 с кодеком H.264; звук AAC, если нужен).

При добавлении файлов сохраняйте понятные имена латиницей, например `autumn-case.webp` или `case-opening.mp4`.
